## Projetos em destaque

### 1. Diagnóstico de Rede com PowerShell
[Ver projeto no GitHub](https://github.com/VanessaMach/diagnostico-rede)
Desenvolvimento de um script PowerShell para auxiliar na identificação de problemas de conectividade em computadores Windows.
**Atividades realizadas:**
- Identificação de interfaces de rede e endereços IPv4
- Consulta ao gateway padrão e servidores DNS
- Testes de conectividade local e externa
- Verificação de resolução de nomes
- Geração de relatórios de diagnóstico
**Aplicação prática:** auxiliar profissionais de suporte técnico na identificação inicial de falhas de rede.

### 2. Laboratório Windows Server
[Ver projeto no GitHub](https://github.com/VanessaMach/lab-windows-server)
Laboratório virtual criado para simular o gerenciamento de arquivos e permissões em um ambiente corporativo.
**Atividades realizadas:**
- Instalação e configuração do Windows Server no VirtualBox
- Criação de usuários e grupos
- Configuração de pastas compartilhadas
- Definição de permissões de acesso
- Testes de acesso autorizado e não autorizado
**Aplicação prática:** compreender como empresas organizam o acesso a arquivos e protegem informações entre departamentos.

### 3. Simulação de Rede Corporativa – Cisco Packet Tracer
Projeto de simulação de uma rede empresarial com diferentes departamentos e regras de comunicação.
**Atividades realizadas:**
- Configuração de switches e roteador
- Segmentação da rede utilizando VLANs
- Configuração de endereçamento IP e DHCP
- Configuração de enlaces trunk
- Implementação de ACLs para controle de tráfego
- Testes de conectividade utilizando ping
**Aplicação prática:** demonstrar como a segmentação de redes contribui para a organização, segurança e administração da infraestrutura corporativa.

### 4. Backup e Recuperação de Arquivos
Laboratório prático de proteção e recuperação de dados.
**Atividades realizadas:**
- Preparação de arquivos para backup
- Configuração de origem e destino
- Execução de cópias de segurança
- Simulação de recuperação de arquivos
- Registro de evidências dos testes
**Aplicação prática:** compreender a importância de manter cópias de segurança e validar a recuperação de informações.

### 5. Monitoramento de Máquinas Têxteis – TCC
Projeto acadêmico desenvolvido em equipe para monitoramento de máquinas industriais.
**Tecnologias:** ESP32, fotoresistor, -- React e MySQL.
**Funcionalidades do projeto:**
- Coleta de dados de funcionamento de máquinas
- Contagem de produção utilizando sensor
- Comunicação entre dispositivo e sistema web
- Visualização de informações em dashboard
**Minha participação:** desenvolvimento e organização de componentes do frontend do dashboard.
